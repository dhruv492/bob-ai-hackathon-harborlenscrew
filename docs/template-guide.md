# Bob AI Innovation Hackathon Submission Template Guide

This repository follows the official Bob AI Innovation Hackathon submission template. Its required files are preserved at the repository root: `submission.yaml`, `README.md`, `src/`, `docs/`, `demo/`, `presentation/`, `CONTRIBUTING.md`, `.gitignore`, and `.github/workflows/validate.yml`.

## Completion checklist

- Fill every required value in `submission.yaml`.
- Keep the README free of placeholder text.
- Keep all source code under `src/` and never commit `.env` files.
- Provide a public or view-only 3-5 minute demo-video URL in `demo/demo-video-link.txt`.
- Keep at least three screenshots in `demo/screenshots/`.
- Keep `presentation/slides.pdf` or `presentation/slides.pptx` in `presentation/`.
- Push to GitHub and confirm the **Validate Submission** workflow succeeds.

See the supplied `Bobathon_Submission_Template_Guide.pdf` for the full evaluator guidance.
