CORE CAPABILITIES

Designed for human-in-the-loop terminal dispatch

Built from operational realities: cold-chain cargo urgency, tidal timing, crane labor limits, and dynamic berth compatibility.

📅

72-Hour Berth Sequencing

Re-sequences incoming vessels by risk priority. Automatically staggers arrival windows to prevent berth conflict while protecting critical cold-chain commitments.

  • Compatible berth matching (B-01 to B-04)
  • Anchorage staging during full-port shutdowns
  • Crane allocation balancing across active vessels
🧠

Explainable Risk Scoring

Every congestion score (0–99) is derived from a transparent, deterministic formula citing specific operational drivers like berth load, dwell, and priority class.

  • Clear citations: "88% berth utilization", "cold chain"
  • Visual Critical (≥70) and Watch flags
  • Human supervisor approval required on reroutes
🌊

What-If Scenario Studio

Stress-test the terminal operating plan before the shift absorbs disruption. Simulate weather severity, individual berth losses (up to 4 berths), and 1-hour arrival variances.

  • Real-time visual berth status chips (✓ / ✕)
  • Dynamic projected shift impact calculation
  • Instant plan re-calculation on slider movement
🤖

IBM Bob Copilot Shift Briefs

Instantly generate structured Bottom Line Up Front (BLUF) shift briefings formatted specifically for IBM Bob skill verification and supervisor handover.

  • Synthesized executive operational summary
  • Prioritized action checklist by urgency
  • Grounded in verified deterministic code

WORKFLOW

From erratic vessel arrivals to an explainable shift plan

01

Fleet Data Management

Vessel arrivals, cargo classifications, dwell windows, and crane requirements are stored in a per-user fleet registry and fetched via REST API on each session.

02

Deterministic Risk Scoring

HarborLens weights terminal utilization, cargo sensitivity, weather, and arrival variance to calculate a transparent, auditable priority score (0–99) for each vessel.

03

72-Hour Berth Sequencing

Vessels are sequenced into compatible berth slots by descending risk score. Rerouted vessels and score changes are highlighted inline when a scenario is applied.

04

Stress-Testing & Handover

Dispatchers test adverse scenarios in the What-If Studio and generate IBM Bob-ready BLUF shift briefs grounded in the same deterministic plan data.

SYSTEM ARCHITECTURE

Production-grade backend with zero bloat

BACKEND

FastAPI & Uvicorn

Python REST API server with full OpenAPI docs at /docs. Runs locally on port 8000 — no cloud account required for the prototype.

DATABASE

SQLite / PostgreSQL

SQLAlchemy ORM with SQLite for zero-config local development. Production-ready with PostgreSQL via DATABASE_URL env variable.

AUTHENTICATION

Custom Auth & SSO Demo

PBKDF2-SHA256 password hashing, HMAC-signed session tokens, and simulated Okta / Microsoft Entra SSO — no external auth service needed.

FRONTEND

Vanilla JS + IBM Plex

Zero-framework HTML5 + CSS with IBM Plex Sans tokens, SVG risk gauges, animated scenario diff, and a guided demo walkthrough mode.
